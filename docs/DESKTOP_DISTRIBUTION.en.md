# Desktop internal research candidate

Extract the complete folder and run DAWLoop.exe. This candidate does not replace public Alpha.2 or automatically overwrite user data and models.

Music Intelligence → Style Lab → Open a completed local research library → Select an excerpt → Find similar excerpts → Listen → Like/dislike → Save favorites as a profile.

The research feature requires existing managed audio components and OMAR metadata. Missing components are configured in Component Manager; system Python is not used as a fallback. Model weights are not bundled or downloaded automatically. Initial batch embedding computation uses the research API documented in packages/music-intelligence/STYLE_LAB_OMAR.md.

Cosine similarity is a research ranking, not a calibrated style probability. Musical similarity needs human listening. This unsigned candidate has not been independently tested on clean Windows. It does not control FL Studio, automatically install updates or upload the library.
