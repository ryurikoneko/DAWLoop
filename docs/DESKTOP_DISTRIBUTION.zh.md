# Desktop 内部研究候选

解压完整目录，运行 DAWLoop.exe。此候选不是公开 Alpha.2 的替换包，不自动覆盖用户数据或模型。

Style Lab 用法：音乐智能 → Style Lab → 打开已完成向量计算的本地研究目录 → 选择参考片段 → 检索 → 试听比较 → 喜欢/不喜欢 → 保存片段画像。

当前研究功能使用已有受管基础音频环境和 OMAR 元数据。没有配置环境时先回到组件管理检查，不调用系统Python替代。候选不包含模型权重，也不自动下载模型。批量向量计算仍使用研究API，见源码 packages/music-intelligence/STYLE_LAB_OMAR.md。

余弦值是研究排序值，不是风格概率；音乐相似性需要人工试听确认。软件未签名，未完成独立干净Windows部署验收。不会控制FL Studio、自动安装更新或上传曲库。
