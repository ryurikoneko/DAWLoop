# 公开内容写作规范 / Public content style guide

适用于全部公开文档、工程说明、Agent 指引、模板、文本归档、资产说明、GitHub 元数据和 Release 文案。

Applies to all public documents, engineering guides, agent instructions, templates, text archives, asset descriptions, repository metadata and release copy.

## 写作原则 / Principles

1. **先说价值。**描述用户任务、操作和结果，再解释实现。 / Lead with user tasks, actions and outcomes.
2. **主动而具体。**使用“导入、试听、编辑、导出”等动作，少用过程汇报。 / Use concrete verbs, not engineering status narration.
3. **可追溯的技术优势。**功能和架构链接到真实代码、演示或验证合同。 / Link technical distinctions to code, demos or contracts.
4. **集中版本信息。**产品页最多一个简短的当前版本说明；功能介绍保留必要配置条件。 / Keep one concise release-notes section per product page while stating necessary setup conditions.
5. **产品与审计分开。**全部公开文字不使用内部判断前缀或置信度标签，事实、建议与未确认事项用自然语言表达。技术档案保留测试结果、来源和验证范围；产品文案避免过程流水账。 / Use plain language throughout public documents, preserving test results, sources and scope in technical records.
6. **中英文平等。**结构、能力、限制、下载和署名一致，英文自然表达。 / Keep language versions equal in scope, with natural writing.
7. **准确描述来源与权利。**区分创作者影响、改编代码、许可与官方身份；保留原始通知。 / Separate creative influence, code provenance, licenses and official identity.
8. **用事实建立吸引力。**不写无证据的“第一、唯一、全面领先”。竞争研究注明来源、日期和比较方法。 / Show value through evidence rather than unsupported market rankings.
9. **安全提醒就地可见。**安装、系统警告、隐私、数据风险和宿主操作权限保留在相关步骤旁。 / Keep safety, privacy and permission requirements beside the action.
10. **发布状态独立。**Desktop发布、源码所在分支、上游能力、现场验证和通知审批分别核对。 / Verify publication, source location, backend capability, live evidence and notification approval independently.

## 发布前审阅 / Review checklist

- 读者在首屏能理解项目、用户和行动入口。 / The first screen explains the product, audience and next step.
- 每项现有功能有依据；计划内容使用未来语气。 / Current claims have references; future work is phrased as future.
- URL、图片、锚点、版本和安装命令有效。 / Links, media, versions and commands are valid.
- Alpha与模型要求清楚，安全与许可未被隐藏。 / Alpha/setup requirements are clear and safety/licensing remains visible.
- 已发布资产与历史证据原样保留。Release改写先批准，通知开关另行授权。 / Preserve assets and evidence; release-copy changes and notification enablement need separate approval.
